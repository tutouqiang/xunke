# 巡课系统

教室巡课记录 Web 应用。扫码 → 自动带出课堂信息 → 填写情况 + 拍照 → 提交 → 后台可查。

## 在线演示

👉 **https://tutouqiangqiang.pythonanywhere.com/**

- 扫码体验（虚构教室）：`/?room=1-101`
- 记录查询：`/records`　教室列表：`/rooms`

> 演示库由 `seed_demo.py` 生成，教室/班级/课程/教师/填表人**全部为虚构占位数据**，
> 不含任何真实学校信息。你的真实数据也永远不会被推上公网。

> **仓库本身是空壳版本**：代码和数据库结构完整，但**不含任何真实数据**
> （没有教室、课表、教师姓名）。本地想跑起来看效果，一条命令灌入虚拟演示数据：
>
> ```bash
> python seed_demo.py    # 生成虚构演示数据（可随时重新 init_empty_db.py 清空）
> ```
>
> 填入真实数据的方法见下面「填入数据」。

## 功能

| 页面 | 说明 |
|------|------|
| **巡课** `/` | 输入/扫码带出房间号，自动显示班级、节次、课程、任课教师；填课堂情况、拍照、提交 |
| **巡课记录** `/records` | 查看/筛选所有巡课记录（按房间号、日期、填表人），可查看详情、删除 |
| **教室一览** `/rooms` | 教室与班级的对应关系，可一键发起巡课 |
| **接口** `/api/resolve` | 按房间号+日期+节次返回 JSON，供二维码/其他系统调用 |

## 快速开始

```bash
pip install -r requirements.txt
python seed_demo.py     # 可选：灌入虚构演示数据，直接体验完整流程
python app.py
#    浏览器打开 http://127.0.0.1:5001/?room=1-101
```

数据库已经是空的可用状态（`init_empty_db.py` 已跑过）。启动后页面能正常打开，
只是查不到数据 —— 首页会显示「系统还是空的」提示。

## 填入数据

需要三份基础数据：**教室对应表**、**节次时间表**、**课程表**。

### 方式一：从 Excel 导入

把三个 Excel 放在一个目录里，运行：

```bash
python import_data.py <Excel所在目录>
```

需要的文件名（固定):

- `ClassDistribution.xlsx` —— 两列：`房间号`、`班级`
- `ClassSections.xlsx` —— 五列：`节次`、`开始时间`、`结束时间`、`周五开始时间`、`周五结束时间`
- `ClassTable.xlsx` —— 五列：`班级`、`星期`、`节次`、`课程`、`任课教师`

⚠️ **`import_data.py` 会重建数据库，已有巡课记录会被清空。**
正式使用后要更新课表，请先备份 `xunke.db` 里的 `records` 表。

### 方式二：手工往数据库里加

用任意 SQLite 工具打开 `xunke.db`，往 `rooms` / `sections` / `schedule` 三张表里插数据即可。

## 技术栈

- **后端**：Python 3 + Flask
- **数据库**：SQLite（无需安装、无需配置、无需密码）
- **前端**：原生 HTML/CSS/JavaScript，移动端优先（巡检员用手机）

## 数据库设计

四张表：

```
rooms     教室号 → 班级
sections  节次 → 起止时间（含周五单独作息）
schedule  班级 + 星期 + 节次 → 课程/教师
records   巡课记录（业务核心表）
```

关键索引：`schedule(class_code, weekday, section)` —— 查课永远是这三个条件的组合。

## 二维码怎么生成

教室门口贴的二维码，内容就是：

```
http://<服务器地址>:5001/?room=1-101
```

把 `1-101` 换成对应房间号即可。巡检员扫码后打开页面，房间号自动带出。

## 拍照说明

手机浏览器访问时才能用摄像头（需要 HTTPS 或 localhost）。
用电脑测试时没有摄像头，**可跳过拍照直接提交**。

## 与原版 xunke1.2 的差异

原版是半成品，跑不起来，本版做了以下改动：

| 项 | 原版 | 本版 |
|---|---|---|
| 数据库 | MySQL（需安装、要密码） | SQLite（零配置） |
| 依赖 | pandas + flask_cors | 只 openpyxl |
| 查课逻辑 | 🐛 行号错位，查出来是错的 | 三条件精确匹配 |
| 不拍照提交 | 🐛 直接 500 崩溃 | 正常提交 |
| 异常处理 | 🐛 出错也报「成功」 | 返回真实错误 |
| 时间判断 | 🐛 写死固定时间戳 | 读当前时间 |
| 查看记录 | ❌ 完全没有 | ✅ 列表+筛选+详情+删除 |
| 前端地址 | 写死 `127.0.0.1:5000` | 相对路径 |
